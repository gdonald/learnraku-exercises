# Enums

An `enum` names a set of related constants, each with an integer value counting up
from zero: `enum Suit <hearts diamonds clubs spades>` makes `hearts` be `0` and
`spades` be `3`. A value's `.value` is its number.

The `Suit` enum is defined. Implement `suit-rank` so it returns the number of a
suit.

`suit-rank(clubs)` should return `2`.
