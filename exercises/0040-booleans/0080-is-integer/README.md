# Smartmatch

The smartmatch operator `~~` asks whether a value matches something: a type, a
pattern, a range. Matching against a type tests membership, and returns a `Bool`.

Implement `is-integer` so it returns `True` when its argument is an `Int`.

`is-integer(42)` should return `True`; `is-integer('42')` and `is-integer(4.2)`
should return `False`.
