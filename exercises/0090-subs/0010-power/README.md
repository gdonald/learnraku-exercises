# Subroutines and signatures

A subroutine declares its parameters in a signature. A parameter can have a
default value, used when the caller leaves it out. The `**` operator raises a
number to a power.

Implement `power` so it raises a base to an exponent, where the exponent
defaults to 2.

`power(5)` should return `25`
`power(2, 10)` should return `1024`
