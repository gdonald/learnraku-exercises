# String comparison

The string comparison operators (`eq`, `ne`, `lt`, `le`, `gt`, `ge`) compare two
strings character by character.

Implement `in-order` so it returns `True` when the first word sorts at or before
the second word alphabetically.

`in-order('apple', 'banana')` should return `True`; `in-order('pear', 'peach')`
should return `False`.
