# Geometric sequences

Given three or more starting numbers, the sequence operator can infer a constant
ratio: `1, 2, 4 ... 64` doubles each time up to `64`.

Implement `powers-of-two` so it returns the powers of two from one up to a limit.

`powers-of-two(32)` should return `[1, 2, 4, 8, 16, 32]`.
