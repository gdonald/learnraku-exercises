# Whatever

A `*` in an expression like `* + 1` builds a `WhateverCode`: a one-argument
function. Passed to `map`, `* + 1` adds one to each element.

Implement `increment-all` so it adds one to every number in a list using a Whatever
expression.

`increment-all([1, 2, 3])` should return `[2, 3, 4]`.
