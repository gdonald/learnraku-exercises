# The ternary operator

The ternary operator `?? !!` chooses between two values based on a condition:
`condition ?? if-true !! if-false`.

Implement `parity` so it returns `'even'` for an even number and `'odd'` for an
odd number.

`parity(4)` should return `'even'`; `parity(7)` should return `'odd'`.
