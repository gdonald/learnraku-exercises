# Logical operators

The logical operators combine boolean values: `&&` (and), `||` (or), `//`
(defined-or), `^^` (exclusive-or).

Implement `can-vote` so it returns `True` only when a person is an adult and a
citizen.

`can-vote(20, True)` should return `True`; `can-vote(20, False)` should return
`False`.
