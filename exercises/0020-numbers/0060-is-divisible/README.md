# Divisibility

The `%%` operator tests whether one number divides another evenly: `10 %% 5` is
`True`, and `10 %% 3` is `False`.

Implement `is-divisible` so it returns whether the first argument is evenly
divisible by the second.

`is-divisible(10, 5)` is `True`; `is-divisible(10, 3)` is `False`.
