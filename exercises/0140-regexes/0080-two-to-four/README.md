# Quantifier ranges

A quantifier can take a range: `\d ** 2..4` matches between two and four digits.

Implement `two-to-four-digits` so it returns `True` when a string is made of two to
four digits and nothing else.

`two-to-four-digits('123')` should return `True`; `two-to-four-digits('12345')`
should return `False`.
