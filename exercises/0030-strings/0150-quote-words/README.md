# Quote words

The `< >` quote-words construct splits its contents on whitespace into a list of
strings, so `<one two three>` is `('one', 'two', 'three')`.

Implement `words-list` so it returns the three words `one`, `two`, `three` as a
list, using quote-words.

`words-list()` should return `['one', 'two', 'three']`.
