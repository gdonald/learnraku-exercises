# Cross with an operator

The cross operator `X` pairs every element of one list with every element of
another. Combined with an operator, `X~` concatenates each cross pair.

Implement `cross-join` so it joins every element of the first list with every
element of the second.

`cross-join(['a', 'b'], ['1', '2'])` should return `['a1', 'a2', 'b1', 'b2']`.
