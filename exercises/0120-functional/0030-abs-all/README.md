# Hyperoperators

A hypermethod call `>>.method` applies a method to every element of a list at once,
returning a new list. `@nums>>.abs` takes the absolute value of each element.

Implement `abs-all` so it returns the absolute value of every number in a list.

`abs-all([-1, 2, -3])` should return `[1, 2, 3]`.
