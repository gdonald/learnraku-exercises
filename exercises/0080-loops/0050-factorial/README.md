# C-style loop

The `loop` keyword with three clauses works like a C `for`:
`loop (my $i = 0; $i < 5; $i++) { }` sets up, tests, and steps a counter.

Implement `factorial` so it returns the product of the whole numbers from one up
to a number using a C-style loop.

`factorial(5)` should return `120`; `factorial(0)` should return `1`.
